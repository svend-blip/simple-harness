# Whip — process cleanup check

Captured after the bounded task + interrupt tests (SIGINT and timeout-killed runs).

```
$ date -Iseconds
2026-08-29T20:08:09+02:00

$ ps aux | grep -E '(^| )(whip)' | grep -v grep | head -5
(no output — no whip processes)

$ pgrep -af 'whip' | grep -v 'bash\|grep'
(no output — no whip processes)
```

After the bounded-task attempt (which ran 132s under `script(1)` then was killed by timeout)
and after the SIGINT test, **zero whip processes remain**.

Confirmed by scanning `/proc/*/comm` for any process whose name contains "whip":
```
orphans: []
```

## Reference

- `whip` is a single static ELF (no separate daemon process). When killed,
  it leaves no children.
- `~/.whip/whip.log` retains historical init lines but no live file handles
  held after exit.
